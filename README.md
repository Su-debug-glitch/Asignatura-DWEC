# Proyectos de Desarrollo Web en Entorno Cliente

Este repositorio contiene los proyectos realizados en clase de desarrollo web en entorno cliente. Los proyectos están desarrollados utilizando principalmente HTML, CSS y JavaScript, para crear interfaces web interactivas y dinámicas.

## Tecnologías usadas

- HTML5
- CSS3
- JavaScript (ES6+)

## Estructura del repositorio

Cada proyecto se encuentra en una carpeta independiente que contiene los archivos HTML, CSS y JavaScript necesarios para su funcionamiento.

## Cómo ejecutar los proyectos

Para visualizar cualquier proyecto, abre el archivo `index.html` correspondiente en un navegador web moderno.
